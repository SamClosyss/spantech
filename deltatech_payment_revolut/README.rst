**REVOLUT Payment Acquirer**

Integrating a Payment Acquirer can help reduce the number of abandoned
baskets or leave the checkout page. The integration of the Odoo system
with the Revolut Payment Acquirer offers customers the opportunity to
pay from their Revolut account for the goods or services they want to
purchase.

Installation
============

To install and configure the Revolut Payment Acquirer go to **Apps**
Module - All Categories –search **Revolut** Module - click the
**Install** button:

Usage
=====





To configure the Payment Acquirer, access the menu **Accounting**:

|Image2|

In **Accounting – Configuration –** click on **Payment Acquirers:**

|Image3|

The Payment Acquirers window will open and access **Revolut**:

|Image4|

Click the **Edit** button and configure the Revolut Payment Acquirer by
filling in the following data:

You will choose one of the *State* options.

-  Disabled;

-  Active;

-  Test mode.

**Credentials**– fill with Revolut Api Key;

    |Image5|

In the **Configuration** section:

|Image6|

-  Displayed as;

-  Submit text;

-  Capture Amount Manually –ticking the box allows you to capture the
   amount;

-  Payment Journal – here you must select a Journal Bank.

**IMPORTANT!!!**

In the Sales Order, the **Capture Transaction** button will look like
this:

|Image7|

3) **Messages**– In this menu, you can set different messages, such as
Help Message, Pending Message, Authorize Message, Done Message or
Canceled Message.

|Image8|

After setting up the Revolut Payment Acquirer, press the **Save**
button:

|Image9|

In this way, when ordering online, the customer can select the payment
method through the Revolut Payment Acquirer.
